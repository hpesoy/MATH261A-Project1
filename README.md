# Progressive Carries and Shot Production in the English Premier League

Simple linear regression project for MATH 261A examining the association between progressive carries and shots among players in the 2024–25 English Premier League season.

**Date of Submission:** September 25, 2026

## Data

Data used in this project is obtained from the [SCORE Sports Data Repository](https://data.scorenetwork.org/soccer/epl-player-stats-2425.html) and was originally sourced from Kaggle. The data are provided under the [MIT License](https://www.mit.edu/~amini/LICENSE.md).

The dataset contains player-level statistics for the 2024–25 English Premier League season. The primary variables used in the analysis are `Progressive Carries` and `Shots`. The final analysis is restricted to players who recorded at least one progressive carry during the season.

The raw dataset is not included in this repository because it was obtained from an external source.

## Repository Structure
